# 🎮 Bangla Fun Games (বাংলা ফান গেমস)

সম্পূর্ণ মোবাইল-বান্ধব, আধুনিক ও আকর্ষণীয় বাংলা গেমিং প্ল্যাটফর্ম। এটি সম্পূর্ণ পিওর **HTML5, CSS3 এবং Vanilla JavaScript** দিয়ে তৈরি। কোনো এক্সটার্নাল লাইব্রেরি, ডাটাবেজ বা পেইড API ছাড়াই যেকোনো সাধারণ ব্রাউজার ও ডিভাইসে ১০০% অফলাইন ও দ্রুত গতিতে চলে।

---

## 🌟 অন্তর্ভুক্ত গেমসমূহ (৬টি পূর্ণাঙ্গ গেম)

1. **🏆 বাংলা কুইজ চ্যালেঞ্জ:**
   - বাংলাদেশ, ইতিহাস, বিজ্ঞান, সাহিত্য ও সাধারণ জ্ঞানের ২৫টি আসল প্রশ্ন।
   - সঠিক/ভুল উত্তর ব্যাখ্যা, প্রগ্রেস বার এবং সেরা স্কোর সংরক্ষণ।
2. **❌⭕ টিক-ট্যাক-টো (কাটাকুটি খেলা):**
   - ২ জন খেলোয়াড় মোড (একই ফোনে বন্ধুর সাথে)।
   - বুদ্ধিমান কম্পিউটার মোড (কম্পিউটার বনাম আপনি)।
   - লাইভ স্কোরবোর্ড ও উইনিং লাইন অ্যানিমেশন।
3. **🎴 মেমোরি কার্ড ম্যাচিং (স্মৃতি পরীক্ষা):**
   - ১৬টি কার্ডের (৮ জোড়া) ৩ডি ফ্লিপ কার্ড ম্যাচিং খেলা।
   - চাল সংখ্যা ও টাইমার ট্র্যাকিং।
4. **🪨📄✂️ পাথর কাগজ কাঁচি (Rock Paper Scissors):**
   - অ্যানিমেটেড ফাইট মোড, কম্পিউটার যুদ্ধ ও উইন স্ট্রিক ট্র্যাকার।
5. **🔢🎯 সংখ্যা অনুমানের খেলা (Number Guessing Game):**
   - ১ থেকে ১০০ এর মধ্যে গোপন সংখ্যা খোঁজার খেলা।
   - লাইভ বড়/ছোট ইঙ্গিত ও সর্বনিম্ন চালের সেরা রেকর্ড।
6. **➕✖️ গণিত স্পিড চ্যালেঞ্জ (Math Speed Challenge):**
   - ৪৫ সেকেন্ডের স্পিড রান, ৩টি লেভেল (সহজ, মাঝারি, কঠিন)।
   - দ্রুত সমাধানের জন্য স্ট্রিক পয়েন্ট বোনাস।

## 🚀 Vercel ও GitHub এ ডিপ্লয় করার নিয়ম

এই রিপোজিটরিটি সরাসরি **Vercel** এ ডিপ্লয় করার উপযোগী।

### Vercel অটোমেটিক ডিপ্লয়:
1. GitHub এ এই কোডটি পুশ করার পর, Vercel Dashboard-এ যান।
2. আপনার GitHub রিপোজিটরিটি সিলেক্ট করে `Import` করুন (Framework: `Other`).
3. সরাসরি `Deploy` বাটনে চাপ দিন—মাত্র ২০ সেকেন্ডে আপনার লাইভ ওয়েবসাইট তৈরি হয়ে যাবে!

### ফাইল কাঠামো:
- `index.html` : মূল ওয়েব পোর্টাল ও গেম লেআউট
- `style.css` : মোবাইল-ফার্স্ট নিয়ন আর্কেড স্টাইল ও অ্যানিমেশন
- `script.js` : সমস্ত গেম লজিক, সাউন্ড সিন্থেসাইজার ও স্কোর সিস্টেম
- `banner.jpg` : হোমপেজ ব্যানার
- `vercel.json` : Vercel কনফিগারেশন
